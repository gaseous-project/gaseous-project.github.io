---
title: Multi-disk ROM Titles
---

For games that require multiple disks or ROMs to run, a media group can be defined.

A media group is a zip file that contains the ROMs that make up the game with an M3U file that contains a list of the files to be used by the emulator to populate the disk selection menu.

# How to create a media group

On the Game info page, go to the ROMs section.
![IMG_0074](https://github.com/gaseous-project/gaseous-server/assets/84688932/c55b1485-4cc0-46db-94a8-ae5ed6adfaf7)

Click on Edit
![IMG_0075](https://github.com/gaseous-project/gaseous-server/assets/84688932/d12400fb-a7f1-4899-b341-92f3186afea2)

Select the ROMs that will make up the media group - the ROMs must all be for the same platform
![IMG_0076](https://github.com/gaseous-project/gaseous-server/assets/84688932/82b822b6-6325-41a4-b09a-388289a67083)

Click the Create Media Group button. The server will begin building the media group.
![IMG_0078](https://github.com/gaseous-project/gaseous-server/assets/84688932/06083390-327c-4a4e-881e-d4719922da0a)
![IMG_0079](https://github.com/gaseous-project/gaseous-server/assets/84688932/2fe22f65-7392-45a2-b98b-23dd783afd44)
![IMG_0080](https://github.com/gaseous-project/gaseous-server/assets/84688932/ab22e062-84ad-444e-8de6-6598fa1cafd3)

Click the Launch button next to the media group to start the emulator with the newly created media group.
