# ROM Management
Gaseous can store ROMs for any platform supported by IGDB (see: https://www.igdb.com/platforms)

# Emulator
The built in emulator supports the following platforms:
* 3DO Interactive Multiplayer
* Amiga
* Amiga CD32
* Arcade
* Atari 2600
* Atari 5200
* Atari 7800
* Atari Jaguar
* Atari Lynx
* ColecoVision
* Commodore 64/MAX
* Commodore 128
* Commodore CDTV
* Commodore PET
* Commodore Plus/4
* Commodore VIC/20
* Family Computer Disk System
* Game Boy
* Game Boy Advance
* Game Boy Color
* Neo Geo Pocket Color
* Nintendo 64
* Nintendo DS
* Nintendo Entertainment System
* PC-FX
* Playstation
* Sega 32X
* Sega CD
* Sega Game Gear
* Sega Master System/Mark III
* Sega Mega Drive/Genesis
* Sega Saturn
* Super Nintendo Entertainment System
* TurboGrafx-16/PC Engine
* Turbografx-16/PC Engine CD
* Virtual Boy

*Note:* Some of the above systems require a BIOS/firmware file in order to execute. To provide your own BIOS files, please read https://github.com/gaseous-project/gaseous-server/wiki/BIOS-System-Firmware
